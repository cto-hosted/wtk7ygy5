# Notepad App

A modern, feature-rich notepad application built with React, TypeScript, Vite, and TipTap.

## Features

- 📝 Rich text editing with TipTap
- 🌓 Light/Dark/Sepia themes
- 🌍 10 language support (i18n)
- 💾 Auto-save functionality
- 📁 File/folder organization
- 🔍 Command palette (Cmd+K)
- ⌨️ Keyboard shortcuts
- 📤 Export to Markdown/HTML/PDF
- 📱 Responsive design

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- TipTap Editor
- Zustand (state management)
- react-i18next (internationalization)

## Getting Started

```bash
npm install
npm run dev
```

## Keyboard Shortcuts

- `Ctrl/Cmd + N` - Create new note
- `Ctrl/Cmd + K` - Open command palette
- `Ctrl/Cmd + S` - Save note
- `Ctrl/Cmd + B` - Bold
- `Ctrl/Cmd + I` - Italic
- `Ctrl/Cmd + U` - Underline

## Export Formats

- Markdown (.md)
- HTML (.html)
- PDF (.pdf)
