# Usage Guide

## Getting Started

### First Time Use
When you first open the application, you'll see the Welcome Screen with an overview of features. Click "Get Started" to create your first note.

### Creating Notes
1. Click the "New Note" button in the sidebar
2. Or use the keyboard shortcut: `Ctrl+N`
3. Start typing in the editor

### Organizing Notes
- **Folders**: Click "New Folder" in the sidebar to create folders
- **Search**: Use the search box in the sidebar to find notes quickly
- Search works across note titles, content, and tags

### Rich Text Editing
Use the toolbar above the editor to format your text:
- **Basic formatting**: Bold, Italic, Underline, Strikethrough
- **Headings**: H1, H2, H3
- **Lists**: Bullet points and numbered lists
- **Links**: Add hyperlinks to your notes
- **Highlighting**: Highlight important text
- **Text alignment**: Left, Center, Right
- **Undo/Redo**: Quickly fix mistakes

### Auto-Save
Notes are automatically saved as you type. You'll never lose your work!

### Themes
Switch between three comfortable themes:
1. **Light Mode** - Bright and clean
2. **Dark Mode** - Easy on the eyes in low light
3. **Sepia Mode** - Comfortable for extended reading

Access themes from the theme icon in the header.

### Language Support
The application supports 10+ languages:
- English, Spanish, French, German
- Chinese, Japanese, Korean
- Arabic, Hindi, Portuguese

Click the globe icon in the header to change languages.

### Exporting Notes
Export your notes in multiple formats:
1. Click the "Export" button when viewing a note
2. Choose your format:
   - **Markdown** (.md) - For developers and technical writing
   - **HTML** (.html) - Open in any web browser
   - **PDF** (.pdf) - For printing and sharing

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | Create new note |
| `Ctrl+K` | Open command palette |
| `Ctrl+F` | Focus search |
| `Ctrl+S` | Save note (auto-saves anyway) |
| `Ctrl+B` | Bold text (in editor) |
| `Ctrl+I` | Italic text (in editor) |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Esc` | Close dialogs |

### Command Palette
Press `Ctrl+K` to open the command palette for quick access to actions.

### Mobile Usage
The application is fully responsive:
- Sidebar can be toggled with the menu icon
- Touch-friendly controls
- Optimized layout for smaller screens

### Data Storage
All notes are stored locally in your browser. No account or internet connection required!

**Important**: 
- Clear your browser data = lose your notes
- Export important notes regularly
- Consider backing up exported files to cloud storage

### Tips for Power Users
1. Use folders to organize notes by project or category
2. Add tags (in the future) for cross-cutting themes
3. Use search operators to find notes quickly
4. Export regularly for backup
5. Use keyboard shortcuts for faster workflow
6. Try different themes for different times of day

### Troubleshooting

**Notes not saving?**
- Check if you have enough local storage space
- Try refreshing the page
- Check browser console for errors

**Search not working?**
- Clear the search box and try again
- Search is case-insensitive

**Export not working?**
- Make sure popup blockers are disabled
- Try a different browser
- Check browser console for errors

**Performance issues?**
- Too many notes can slow down the app
- Consider archiving old notes
- Export and delete notes you don't need

### Privacy & Security
- All data stored locally in your browser
- No data sent to servers
- No tracking or analytics
- Open source - review the code yourself
