# Professional Notepad

A modern, feature-rich notepad application with international support.

## Features

- Rich text editing with TipTap editor
- Multi-language support (10 languages)
- Dark/Light theme
- File management with folder structure
- Auto-save functionality
- Keyboard shortcuts
- Export to various formats
- Command palette for quick actions
- Responsive design

## Supported Languages

- English
- Spanish
- French
- German
- Chinese (Simplified)
- Japanese
- Korean
- Arabic
- Hindi
- Portuguese

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- TipTap (rich text editor)
- Zustand (state management)
- react-i18next (internationalization)

## Getting Started

### Install Dependencies

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Keyboard Shortcuts

- `Ctrl/Cmd + S` - Save note
- `Ctrl/Cmd + K` - Open command palette
- `Ctrl/Cmd + B` - Bold
- `Ctrl/Cmd + I` - Italic
- `Ctrl/Cmd + U` - Underline
- `Ctrl/Cmd + N` - New note
- `Ctrl/Cmd + F` - Search notes
